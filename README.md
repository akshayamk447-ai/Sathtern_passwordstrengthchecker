🔐 Password Strength Checker

A browser-based cybersecurity project that evaluates password strength and generates secure random passwords using HTML, CSS, and JavaScript.

🌐 Live Demo

https://akshayamk447-ai.github.io/Sathtern_passwordstrengthchecker/

✨ Features

* Real-time password strength assessment
* Password length and character-type checklist
* Strength score and visual progress bar
* Show/hide password option
* Secure random password generator
* Copy generated password to clipboard
* Responsive user interface

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

🚀 How to Run Locally

1. Clone this repository:

git clone https://github.com/akshayamk447-ai/Sathtern_passwordstrengthchecker.git

2. Open the project folder.
3. Open index.html in your web browser.

🎯 Project Objective

To demonstrate basic cybersecurity awareness by helping users understand password-strength characteristics and create stronger, unique passwords.
